# 💻 IT Center Website

**IT Center Website** is a modern, responsive educational website designed for an IT learning center. Built with HTML, CSS, and JavaScript, it provides an elegant and user-friendly experience for showcasing programming courses, educational services, and contact information.

Whether you're promoting an IT academy, coding bootcamp, or technology training center, **IT Center Website** offers a clean, professional, and responsive web experience.

---

# ✨ Features

## 🔐 Backend Integration

A complete backend built with Node.js and Express.js handles application logic and API requests.

## 🗄️ MongoDB Database

Store application data securely using MongoDB and Mongoose.

## 🌐 REST API

Backend provides scalable RESTful APIs for future frontend integration.

## 📱 Responsive Design

Fully responsive interface optimized for desktops, laptops, tablets, and smartphones.

## 🎨 Modern UI/UX

Enjoy a beautiful interface featuring:

- Modern clean design
- Responsive navigation
- Hero section
- Interactive buttons
- Smooth animations
- Gradient backgrounds
- Mobile-friendly layout

## 🚀 Fast Performance

Optimized HTML, CSS, and JavaScript provide fast loading speeds and smooth user interactions.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/muxriddin-web/IT_center.git
```

---

## Navigate into the Project

```bash
cd IT_center
```

---

## Install Dependencies

```bash
cd backend
npm install
```

---

## Configure Environment Variables

Create a `.env` file inside the backend directory.

Example:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

---

## Start the Backend Server

```bash
npm run dev
```

---

## Run the Frontend

Open

```text
index.html
```

in your browser.
